# 名詞與邊界

版本：1.0.0｜2026-09-22

| 固定名稱 | 中文 | 本版定義或邊界 |
|---|---|---|
| Goal | 目標 | 包含意圖、範圍及預期結果；不再並列 Intent |
| Context | 上下文 | 當次輸入、相關資料與限制；RAG 是取得上下文的方法之一 |
| Reason | 推理 | 分析依據及提出方案；不等於取得行動授權 |
| Decide | 決策 | 依條件與權限選擇行動、核准、轉交或停止 |
| Action | 行動 | 實際執行；含取得資料等工具操作 |
| Evaluate | 驗證 | 依驗收標準檢查結果 |
| Acceptance | 驗收標準 | VAC 的第四欄；包含品質、必要條件與適用 KPI |
| KPI | 關鍵績效指標 | 可量化的衡量方式，不能取代所有驗收條件 |
| Human Governance | 人類治理 | 設計、運行與變更全程的制度及控制 |
| VAD | 視覺化工作設計 | Visual Agent Design；看懂工作 |
| VAC | 任務規格 | Visual Agent Contract；定義工作並引用 DC |
| DC | 決策規則 | Decision Contract；管住決策並記載自主權 |
| A1–A4 | 自主權分類 | 本專案自訂；分類依授權範圍而非模型或 Agent 數量 |
| Promptless | 減少臨時提示 | 重用規格及當次輸入，不代表完全沒有提示 |
| Business Outcome | 企業成果 | 目標及驗證所關心的價值，不另設一層 |

全文的六環節使用同一組英文名稱；其文法形式不同不影響其作為固定標籤。Decision 是 DC 的欄位名稱，Decide 是工作環節名稱。
