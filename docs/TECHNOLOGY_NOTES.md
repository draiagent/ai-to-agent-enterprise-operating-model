# 技術案例維護頁

版本：1.0.0｜2026-09-22

方法論不綁定特定產品。此頁說明技術的可能用途，不是產品能力、效能或價格的最新查核報告。

| 類別 | 可支援的工作 | 避免混淆 |
|---|---|---|
| LLM | 分析、生成、工具選擇與結果檢查 | 模型不等於完整 Agent 系統 |
| ChatGPT、Claude、Gemini 等產品 | 視功能與設定支援多個環節 | 產品名稱不能一律等同 Reason 模組 |
| 規則程式、分類模型、決策模型 | 提供判定或候選結果 | 預測結果不會自行授予行動權 |
| RAG、Memory、Database | 取得與管理上下文 | 三者不是同一種技術或元件 |
| Skills、Tools | 提供可重用程序與具體操作 | 技能可影響多個環節，不只 Action |
| MCP、API、A2A | 連接工具、服務或代理協作 | 協定與介面本身不保證正確性或授權 |
| Codex、Claude Code 等 Coding Agent | 協助建構或執行跨環節工作 | 不必硬塞成單一元件 |

## Jev 案例的保留方式

先前討論以 Jev 作為決策模型的候選案例。核心方法論不依賴它。本版不轉載未查證的速度、成本、準確率、免費承諾或「無幻覺」說法。

即使實作提供有型別的輸出，格式合法也不代表內容正確；模型分數與授權規則仍要分開驗證。採用任何產品前，另查官方文件並用企業自己的資料評估。

## 更新紀錄欄位

每新增產品案例，記錄：產品與版本、官方來源、查閱日期、實測任務、測試資料、結果、限制及對應工作環節。沒有查核日期與來源時，標示為待驗證案例，不寫入固定教材的能力結論。
